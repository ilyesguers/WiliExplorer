# ◈ WiliExplorer 6.1

مستكشف بصري متقدم لتجارب **Roblox**، بواجهة متجاوبة صُممت للهاتف والكمبيوتر.

> الإصدار 6 يركز على الوضوح، سرعة الوصول، اللمس، وتوحيد تجربة الصور والأصوات والمجسمات والملفات.

## ما الجديد في 6.1

- **وحدة مطوّر جديدة بالكامل:** بديل احترافي ومتجاوب لقائمة Klimbo القديمة، دون سكربتات خارجية أو ميزات محلية مضللة.
- **فحص آمن ومجزّأ:** إلغاء، تقدم مباشر، حدود للذاكرة، بحث وفلاتر ونتائج قابلة للتحديد والنسخ.
- **لوحة أداء:** FPS والذاكرة والاستجابة ومدة الجلسة بتحديث اقتصادي للبطارية.
- **Loader فعلي:** تحركه `Config.Modules`، يستخدم cache عند انقطاع الشبكة، ويعرض تقرير أخطاء الوحدات.
- **أمان صريح:** المفاتيح ليست في المستودع؛ التحقق الخادمي وتاريخ الانتهاء موضحان في `SECURITY.md`.
- **أدوات مطوّر:** فحص نحوي آلي، CI، وbuild manifest بتوقيعات SHA-256.
- **واجهة مستكشف موحّدة:** لا تنزيلات داخلية، تحليل واحد، بحث كامل للشجرة، وتخطيط Sidebar تلقائي.
- **أصول يديرها المشرف:** الصور والأيقونات المرفوعة موثقة في `assets/` ومعرّفة مركزياً في `Theme/Assets.lua`.
- **تصميم موحّد:** ألوان ومسافات وحواف وحالات تفاعل من `DesignSystem` مركزي.
- **تجاوب فعلي:** الواجهة تعيد ترتيب نفسها عند تدوير الهاتف أو تغيير حجم الشاشة.
- **بحث أذكى:** بحث بالاسم والنوع والمسار، اقتراحات، سجل بحث، واختصار `Ctrl + F`.
- **فلاتر واضحة:** شرائح قابلة للتمرير للسكربتات والمجسمات والصور والأصوات والقيم.
- **أيقونات دلالية:** قاموس أيقونات مركزي ومتناسق بدل الاختصارات النصية القديمة.
- **محرر صور أفضل:** معاينة كبيرة، تخطيط عمودي على الهاتف، شفافية وطرق عرض وأدوات Asset ID.
- **مشغل صوت أفضل:** أزرار لمس كبيرة، شريط تقدم، Loop، Volume وPlayback Speed وSound ID.
- **أداء الهاتف:** تقليل المؤثرات الثقيلة تلقائياً على الشاشات الصغيرة.
- **دعم عربي/إنجليزي:** العربية افتراضياً مع نصوص أوضح ومساعدة لاتجاه RTL.

## الوحدات الأساسية

| المسار | الوظيفة |
|---|---|
| `src/Loader.lua` | تحميل الوحدات بالترتيب ومعالجة فشل الوحدات الاختيارية |
| `src/Config.lua` | الإصدار والإعدادات الافتراضية وقائمة الوحدات |
| `src/Utils/DesignSystem.lua` | التصميم المتجاوب، tokens، والأدوات المشتركة |
| `src/Utils/Icons.lua` | أيقونات دلالية موحدة |
| `src/Utils/Language.lua` | الترجمة العربية والإنجليزية |
| `src/UI/SearchBar.lua` | البحث والاقتراحات والفلاتر |
| `src/UI/TreeView.lua` | شجرة العناصر والبحث حسب المسار والنوع |
| `src/UI/ImageEditor.lua` | معاينة وتعديل خصائص الصور |
| `src/UI/SoundEditor.lua` | تشغيل وتعديل خصائص الأصوات |

## التشغيل

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ilyesguers/WiliExplorer/main/src/Loader.lua"))()
```

يتطلب التنفيذ بيئة تدعم `HttpGet` و`loadstring`. بعض خصائص القراءة أو النسخ تعتمد على قدرات بيئة التشغيل، لذلك يتعامل المحمّل معها كوحدات اختيارية عند الإمكان.
