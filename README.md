# ◈ WiliExplorer 7.0

مستكشف بصري متقدم لتجارب **Roblox**، بواجهة متجاوبة صُممت للهاتف والكمبيوتر.

> الإصدار 7: **عارض شامل لكل الأنواع** — معاينة حقيقية لكل ملف مهما كان نوعه (كود، صوت، صورة، فيديو، مجسم ثلاثي الأبعاد، حركة، واجهة، تأثير، إضاءة، قيمة، اتصال...) وواجهة حية بأزرار مرتبة تلقائياً.

## ما الجديد في 7.0

- **عارض شامل لكل ملف:** معاينة مخصصة لكل نوع بدل شاشة معلومات ثابتة — اقرأ §الوحدات الأساسية.
- **معاينة ثلاثية الأبعاد:** المجسمات والأجزاء تُعرض داخل `ViewportFrame` مع كاميرا ذكية وتدوير تلقائي.
- **تبويب خصائص قابل للتعديل** داخل العارض لكل عنصر (نصوص/أرقام/منطقي + حفظ فوري).
- **شريط أدوات مرتب تلقائياً:** أزرار النافذة في `UIListLayout` — لا تداخل ولا مواضع عشوائية — مع تلميحات.
- **أيقونات منفصلة عن النصوص دائماً:** لا تشابك مع RTL — سجل `Icons` مركزي يغطي +120 نوع.
- **حياة في الواجهة:** وحدة `Animations` أصبحت محمّلة فعلاً وتُستخدم في دخول الشاشات وأزرار Hover/Press.
- **شجرة أقوى:** 13 فلتر فئة، فرز بالاسم/النوع، قائمة سياق بالضغط المطوّل، زر فتح لكل صف.
- **أدوات مطوّر أعمق:** فحص صارم بصياغة Lua حقيقية (fengari) + وثيقة معمارية كاملة في `docs/ARCHITECTURE_AR.md`.

## الوحدات الأساسية

| المسار | الوظيفة |
|---|---|
| `src/Loader.lua` | تحميل الوحدات بالترتيب من Config مع cache ومعالجة الفشل |
| `src/Config.lua` | الإصدار والإعدادات وقائمة الوحدات المحمّلة |
| `src/Core/FileScanner.lua` | تصنيف +120 نوع، معلومات غنية، قراءة/كتابة المصدر، بحث مجزّأ |
| `src/UI/FileViewer.lua` | **العارض الشامل v7** (معاينة لكل الأنواع + خصائص + عناصر فرعية) |
| `src/UI/TreeView.lua` | الشجرة مع فلاتر كاملة وفرز وقائمة سياق |
| `src/UI/MainFrame.lua` | الإطار الرئيسي وشريط الأدوات المرتب تلقائياً |
| `src/UI/KlimboMenu.lua` | وحدة المطوّر (فحص/أداء/إعدادات) بدون سكربتات خارجية |
| `src/Utils/Highlighter.lua` | تلوين Lua كامل للأكواد |
| `src/Utils/Icons.lua` | سجل الأيقونات المركزي + أدوات فصل الأيقونة عن النص |
| `src/Utils/Language.lua` | الترجمة العربية والإنجليزية + RTL |
| `src/Utils/DesignSystem.lua` | التصميم المتجاوب وtokens |

## التشغيل

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/ilyesguers/WiliExplorer/main/src/Loader.lua"))()
```

يتطلب التنفيذ بيئة تدعم `HttpGet` و`loadstring`. بعض خصائص القراءة أو النسخ تعتمد على قدرات بيئة التشغيل، لذلك يتعامل المحمّل معها كوحدات اختيارية عند الإمكان.

## أدوات المطوّر

```bash
npm install
npm run check   # فحص صياغة + سياسات + فحص صارم (fengari)
npm run build   # build manifest مع توقيعات SHA-256
```

اقرأ `docs/ARCHITECTURE_AR.md` لخريطة الملفات الكاملة وترابط الوحدات والعيوب التي أُصلحت.
