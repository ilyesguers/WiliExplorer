# دليل WiliExplorer 7.0

## الاستخدام السريع
1. افتح المستكشف واختر خدمة.
2. ابحث باسم العنصر أو نوعه أو مساره، وفلتر بـ 13 فئة أو رتّب بالاسم/النوع.
3. اضغط على عنصر لفتح **العارض الشامل** — معاينة حقيقية لكل نوع.
4. اضغط مطوّلاً على أي صف لفتح قائمة السياق (نسخ/استنساخ/حذف).

## العارض الشامل v7
كل ملف يُعاين فعلياً مهما كان نوعه:

- **سكربتات:** كود ملوّن بالكامل + تعديل/حفظ/تشغيل.
- **أصوات:** مشغّل مدمج (تشغيل/إيقاف/تكرار/مستوى/سرعة).
- **صور وفيديو:** معاينة كبيرة + نسخ المعرف.
- **مجسمات وأجزاء:** معاينة ثلاثية الأبعاد بتدوير تلقائي.
- **حركات:** بيانات + تشغيل على شخصيتك.
- **واجهات:** نسخة مصغّرة بمقياس قابل للتحكم.
- **تأثيرات وإضاءة:** معاينة حية وتحكم مباشر.
- **قيم واتصالات:** محرر مدمج + إطلاق/استدعاء.
- **أي نوع آخر:** معلومات غنية + تبويب خصائص قابل للتعديل + وسوم + Attributes.

## شريط الأدوات
أزرار النافذة (لغة/DEV/تصغير/إغلاق) مرتبة تلقائياً بحاوية `UIListLayout` — لا تداخل أبداً — مع تلميحات عند التمرير وأيقونات منفصلة عن النص.

## وحدة المطوّر الجديدة
زر `DEV` يفتح مساحة موحّدة لا تعتمد على أي سكربت خارجي:

- **نظرة عامة:** اسم التجربة وإحصاءات آخر فحص.
- **الفحص:** فحص تدريجي قابل للإلغاء مع بحث وفلاتر وحد أقصى للذاكرة.
- **الأداء:** FPS والذاكرة والاستجابة ومدة الجلسة.
- **الإعدادات:** توفير الطاقة، الحركة، حجم الدفعة وحد العناصر.

الفحص للعرض المحلي فقط ولا يطلق RemoteEvents أو يثبت metatable hooks. أزيلت الميزات التي كانت محلية فقط وتُعرض وكأنها تغيّر الخادم.

## الهاتف
- تدوير الجهاز يعيد ترتيب النافذة تلقائياً.
- جميع عناصر التحكم الجديدة لا تقل عن 44px تقريباً.
- اسحب صفوف التبويبات والفلاتر أفقياً.
- منزلقات الصور والصوت وإعدادات الفحص تدعم اللمس.
- وضع توفير الطاقة يقلل تحديث القياسات ويوقف المؤثرات الثقيلة.

## اللغة وRTL
العربية افتراضية. زر `EN` يحوّل للإنجليزية و`AR` يعيد العربية. يطبق النظام اتجاه RTL ومحاذاة مناسبة على النصوص القابلة لذلك.

## المفاتيح
لا توجد مفاتيح إنتاج داخل المستودع. اضبط `Config.Security.Endpoint` لخدمة تحقق خادمية واقرأ `SECURITY.md` قبل الإصدار.
