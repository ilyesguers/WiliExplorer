# دليل WiliExplorer 6

## الاستخدام السريع
1. افتح المستكشف واختر خدمة.
2. ابحث باسم العنصر أو نوعه أو مساره.
3. استخدم شرائح الفلترة لإظهار السكربتات أو المجسمات أو الصور أو الأصوات أو القيم فقط.
4. اضغط على عنصر لفتح المعاينة والأدوات المناسبة لنوعه.

## الهاتف
- تدوير الجهاز يعيد ترتيب النافذة تلقائياً.
- اسحب صف الفلاتر أفقياً للوصول إلى جميع الأنواع.
- منزلقات الصور والصوت تدعم اللمس والسحب.
- المؤثرات الخلفية الثقيلة تتوقف تلقائياً للمحافظة على الأداء.

## اللغة
العربية هي اللغة الافتراضية. استخدم زر `EN` للإنجليزية، ويمكن الرجوع عبر زر `AR`.
