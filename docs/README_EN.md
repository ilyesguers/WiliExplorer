# WiliExplorer 6 Guide

## Quick start
1. Open Explorer and select a service.
2. Search by item name, class, or full path.
3. Use filter chips to focus on scripts, models, images, sounds, or values.
4. Select an item to open the preview and type-specific tools.

## Mobile
- Rotating the device automatically recalculates the layout.
- Swipe the filter row horizontally to reach every category.
- Image and sound sliders support touch dragging.
- Expensive ambient effects are disabled on small screens to preserve performance.

## Language
Arabic is the default language. Tap `EN` for English and `AR` to switch back.
